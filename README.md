# 🎵 Responsive Music Player

This project is a **Responsive Music Player** built using **HTML, CSS, and JavaScript**.

It provides a simple and interactive interface for playing and controlling music across different screen sizes.

## 🚀 Features

* Play and pause music
* Next and previous song controls
* Responsive design
* Music progress bar
* Volume control
* Song information display
* Works on desktop, tablet, and mobile devices

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 Objective

The main objective of this project is to practice **responsive web design, CSS styling, and JavaScript functionality** by creating an interactive and user-friendly music player.
